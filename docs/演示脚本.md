# 3 分钟演示路线：《问津 Pathfinder》

## 核心表达（一句话）

> 用知乎上的经历作为参照，让人在看见别人的后来之前先留下自己的判断；看过之后再回看、修正，并把自己愿意分享的变化留给下一位。

不使用的话术：不说"预测人生"、不说"AI 帮你做正确决定"——当前能力是"参照＋记录＋自愿分享"，台词与能力一致。

## 时间线

| 时间 | 动作 | 讲什么 |
|---|---|---|
| 0:00–0:20 | 打开首页，停留一条经历 | "这是知乎上真实发生过的等待：有人 6.23 谈完薪，6.30 深夜收到 offer。我们做的产品，就为这一周。" |
| 0:20–0:50 | 进入关卡「等消息的这一周」，选择行动＋填理由 | "**先留下自己的判断**——选'暂按原计划等待'，理由写原话。这一步在揭晓之后被冻结，不可改写。" |
| 0:50–1:40 | 点揭晓，浏览"后来"卡片 | "现在才看见不同人的后来。注意两件事：每条引文逐字来自知乎原文，带作者和来源；每张卡片标注**条件差异**和**未知**——拿到 offer 不等于入职，页面不悄悄补结论。" |
| 1:40–2:10 | 填"看过之后的想法"，保存 | "现在的想法和起初的判断**并排保存**。回看时能解释：我当时为什么这么想、依据是哪条经历。" |
| 2:10–2:40 | 选择分享→生成链接→另一设备/隐身窗口打开 | "我**自愿**分享一部分给下一位。内容先存本机，管理凭据只有我的设备有。" |
| 2:40–3:00 | 演示撤回，链接变不可读 | "随时可撤回，撤回后链接立刻不可读。同意公开和可撤回，是同一条通路的两端。" |

## 评委应当看见的三件事

| 评委看到什么 | 页面/操作如何证明 |
|---|---|
| 知乎内容提供了什么 | 卡片引文逐字对应原文，可点来源链接；素材登记表（`backend/contract/素材来源.json`）含 URL＋原文摘要 sha256＋核对范围 |
| 我们新增了什么 | "先记后看"的冻结机制；前后想法并排；记录与来源绑定 |
| 参与如何继续 | 保留触动自己的来源（来源摘录随记录保存）、追加变化（标注为演示）、明确选择是否公开 |

## 演示纪律（必守）

1. **跨时间追加必须口头标注"这是演示数据"**——页面亦有标注，不假装是长期真实用户数据
2. 三个辅助入口（真实搜索、故事库、问津）如实说明当前能力，不夸大
3. 真实搜索作为**补充展示**（输入"等 offer 审批"展示真实候选＋UTM 已剥离），主路线用已核验的关卡案例保证可重复
4. 遇到限流/超时：如实说"上游限流，页面提示了等待时间"——降级文案本身是设计的一部分（官方检查清单第 6 条）
5. 撤回演示后，把链接再点一次让 404 可见
