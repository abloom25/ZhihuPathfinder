## 环境与凭据

本次临时页面：http://127.0.0.1:18131/ 。密钥通过关闭回显的标准输入注入临时后端进程，仅用于向 developer.zhihu.com 发出请求；没有写进源码、仓库、前端资源或日志。此进程退出后，临时环境不保留密钥配置，也不代表公网已配置。

正式后端已支持 ZHIHU_ACCESS_SECRET 或 ZHIHU_ACCESS_SECRET_FILE。由部署负责人通过其已有 Secret 配置方式注入，不要把密钥放进前端环境变量。配置后的验收可运行：

```sh
LIVE_BASE_URL=http://127.0.0.1:8787 LIVE_QUERY='等offer 后来 收到' node backend/scripts/verify-live-search.mjs
```

该脚本只向已配置的后端发送搜索，不读取密钥；不是默认离线测试的一部分。实际部署地址替换 LIVE_BASE_URL。可设置 LIVE_EXPECT_MODE=live 或 cached 约束预期来源；非空结果、状态、query 对应关系和前端契约不符合时退出失败。
