# 结论审核与局部降级：离线验证

本轮未通过自动展示门槛。局部降级机制有效，但审核误拒过多；比赛版继续使用来源摘录和已有核验案例，解释能力留在实验区。现有 API 和前端契约未接入审核器。

## 做了什么

固定第三轮 B 提取流程，新增独立、无状态的逐条审核调用，检查主体、事件、情态、归属与表述范围。模型引用原文编号，程序核验编号和返回一致性；这只能验证结构，不能证明语义正确。审核与提取使用同一模型，不构成独立事实核验。

审核不通过时只降级对应内容：结论退回摘录，结果标为未知，关系撤掉；其他保留项和原文仍在。所有保留项仅供实验，automaticDisplayAllowed 始终为 false。

运行前冻结 8 组正误对照、3 条原始材料的判定依据、提示词及门槛；正误标签不发送给模型。没有根据结果调整提示词或重试挑选成功响应。原始材料来自已有知乎 API 片段，不代表完整文章或线下事实。

## 结果

| 检查 | 结果 |
|---|---|
| 8 条正确对照 | 保留 6 条，2 条因网络失败降级 |
| 8 条错误对照 | 6 条被语义拒绝，2 条因网络失败降级；误放 0 条 |
| 原始材料产生的 12 条有依据结论 | 保留 3 条；5 条被语义误拒，4 条因服务失败降级 |
| 原始材料产生的 2 条无依据结论 | 1 条被语义拒绝，1 条因网络失败降级；误放 0 条 |

3 条原始材料中，H03-01 未产生候选，不能计作审核成功。另外两条共 14 个候选。标签由本助手对照原文人工判定，不是独立盲评。

预设门槛为：对照错误误放 0、正确至少保留 7/8；原始材料错误误放 0、正确内容降级比例不超过 20%。本轮正确对照仅保留 6/8；原始材料正确内容降级 9/12（75%）。即使排除服务失败，8 条取得审核响应的正确内容仍有 5 条被误拒。因此不能把问题归结为网络波动。

无审核的实验基线会保留全部候选，本轮确实减少错误进入保留区，但损失过多正确内容。此基线从未在产品中自动展示。样本较小，零误放也包含服务失败的保守回退，不能证明可靠性。

## 具体失败与有效机制

审核器否定了工作经历上下文中的“从前端搞到了后端”、作者所在批次薪资比较等明确自述，额外要求精确时间、状态变化或因果证据。审核 pair-2-b 虽正确拒绝了新申请已获 offer 的说法，却错误地把旧 offer 解释成别人的经历：判决正确不等于理解正确。

H04-04 保留 c1、c2，降级 c3、r1，原文完整保留。关系撤掉没有连带删除其他结论，证明局部降级能够隔离损失。保留内容只表示来源支持作者这样说，不代表身份、录取或因果关系得到外部证实。

38 项自动测试通过，其中新增 5 项覆盖审核结构、局部降级、服务失败和标签隔离。测试通过不替代上面的语义评估。
