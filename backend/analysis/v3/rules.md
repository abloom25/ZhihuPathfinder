# 本轮判定规则（调用前固定）

目标是保留有依据的作者变化，不要求把整篇文章完整分类。以结论为单位判断，未知项可以为空或省略；可选说明不是门槛。不存在的引用、重复ID和缺失必要分类只影响对应条目。

先提取：subject区分author/other/example/uncertain；kind区分occurred/intention/advice/uncertain。第一人称引用话术不是作者亲历。作者提出辞职是已发生行动，但期待离职不是完成离职。作者自述工作习惯可保留，却不能把一般建议升级成求职结果。

再判断关系：同一机会/目标的准备、等待、结果与后续通常连续；换日期或阶段不足以另起事件。新公司机会或明确再次开始才有独立事件依据。关系不明时保留独立的原文事实，不宣称它们是两段独立经历，也不默认强行合并。

程序保证引用可还原、类型与结构明确、结论局部失败和关系不能引用被拒结论。subject/kind和事件关系仍是模型判断，不能称已语义核验。事实和愿望同句时，以较细原文单元分别处理；不把含“希望”的整个段落删除。原文始终可见，不自动输出confirmedEpisodes。

计分：逐项对照原文评估事实支持、亲历归属、计划与事实、关系合并或拆分。统计保留/待核对/拒绝、人工确认有用条目及误判，不能只给全篇0或1。部分有效条目必须保留；不能因门槛降低把错误算成有效。

固定规则和接口后，比较同一模型的两种提取提示词，关系提示词与代码相同。6例旧回归加4例本轮新验证；材料此前可见，非盲测。验证结果不用于本轮调参。只做一次成对对照，不换模型混淆变量。
